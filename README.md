# Java File Monitor

## Project Description
A Java application that monitors a specified
directory for file activities.

## Features
- Detects file creation.
- Detects file deletion.
- Detects file modification.
- Displays file activity in the console.

## Technologies Used
- Java
- Java NIO
- WatchService API

## How to Run

1. Make sure Java JDK is installed.
2. Create a folder named notes inside D drive.
3. Compile the program:

   javac FileMonitor.java

4. Run the program:

   java FileMonitor

## Output
Displays the type of file event and file name
in the Command Prompt.
